# AI_USAGE.md — Отчёт об использовании ИИ

## 1. Обзор и процесс разработки
- Проект: SPA аукционов (React 19 + TS + TanStack Router/Query + RHF + Zod + MSW + Tailwind v4)
- Срок: ~5 часов
- Роли: планирование — сам; весь код — модель DeepSeek V4 Flash
  в редакторе opencode desktop

## 2. Что делалось с помощью ИИ
- Весь код написан моделью строго по составленному мной детальному плану
  (компоненты, страницы, API-клиент, схемы, моки, тесты, стили)

## 3. Что делал сам
- Детальный план: этапы, порядок работ, как и что делать
- Методология TDD: для ключевых участков бизнес-логики сначала писались тесты, затем реализация
- Ручная проверка каждого компонента на явные ошибки
- Рефакторинг после проверок
- Ключевые бизнес-решения (семантика НДС, валидация ставок min/max/step)

## 4. Что проверялось особенно внимательно
- Бизнес-логика: расчёт с НДС/без НДС, границы допустимых ставок
- Каждый компонент UI — просмотр на явные ошибки
- Формы и валидация

## 5. Оставшиеся риски
- Мало времени (~5 часов) → возможны сырые места и неработающие краевые случаи
- Тесты покрывают основные сценарии, но не всё

## 6. Что можно улучшить при наличии ещё одного дня
- Полировка UX, расширение тестового покрытия, обработка edge кейсов

## 7. Сохранённые ключевые решения
- UI Library: Astryx + Tailwind bridge (правило «без кастомных CSS-оверрайдов», порядок CSS-слоёв)
- Testing: Vitest (юнит) + Playwright (e2e), MSW в dev
